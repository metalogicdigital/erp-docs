==============
How we deliver
==============

The business capabilities in our case studies are only as good as the way they are built,
tested, shipped and supported. Every MetaLogic engagement runs on the same engineering system:

.. cards::

   .. card:: SDLC and the Project Planner
      :target: delivery/sdlc

      Requirements to themes, features, epics, stories and defects, with every pull request and
      commit traced back to the work item that asked for it.

   .. card:: CI/CD pipeline
      :target: delivery/cicd

      Git-driven, change-aware module upgrades, immutable release images, rolling deploys with
      automatic rollback, and night-window production cut-overs.

   .. card:: Defect-fixing pipeline
      :target: delivery/defect_pipeline

      From a production screenshot to a reviewed fix: read-only investigation, local
      reproduction, root cause, regression tests and a linked pull request, with an AI agent that
      can run the whole loop.
